These indicators are measured live in this page, not hard-coded.

  • Network locked: a Content Security Policy (connect-src 'none') makes the browser refuse every outbound request. Any attempt is counted here and turns this indicator red.
  • Local code only: lists every file the browser loaded and flags anything from another origin.
  • Nothing saved: the code never calls cookies, localStorage, sessionStorage or IndexedDB. Reload the page and your table is gone.
  • Try it yourself: open DevTools → Network, then edit and paste. No requests appear. Or turn off Wi‑Fi: everything keeps working.
  • Read the source: about 900 lines of plain JavaScript, no dependencies. See SECURITY.md.
